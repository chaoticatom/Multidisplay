Type anything in the Ask bar - “a calm sunset with stars”, “draw a pixel cat” - and the AI sets up the display or draws it.
Control the display with an Echo on your home network - no skill or Amazon set-up. The display shows up as smart lights.
Then say “Alexa, discover devices” (or Alexa app → Devices → + → Add Device → Other → “Discover Devices” - it's Wi-Fi, not Bluetooth; don't pick Philips Hue, that asks for a real bridge's button). The Echo must be on the same Wi-Fi as the Pi. Then try:
• “Alexa, turn off Display” / “turn on Display”
• “Alexa, set Display to 40 percent” (brightness)
• “Alexa, set Volume to 30 percent”
• “Alexa, turn on Fireworks” - each favourite effect (★) and saved scene is a device; re-discover after changing them
Tip: in the Alexa app, put them in a Routine (“Alexa, party time”).
Your own Alexa skill
For more than on/off: “Alexa, ask led wall to show fireworks / make it a calm sunset / tell the face hello / tell me a joke / brightness 50 percent”. Free, private to your Amazon account; uses your Cloudflare address.
Set-up steps (about 15 minutes, once)
  1. On a computer, sign in at developer.amazon.com/alexa/console/ask with the same Amazon account as your Echo.
  2. Create Skill → name “LED wall” → your language (English UK if your Echo is UK) → type Other → Custom → hosting Provision your own → template Start from scratch → Create.
  3. Left menu Interaction Model → JSON Editor: delete what's there, paste the model from this link (it has your effects), Save, then Build skill.
  4. Left menu Endpoint → HTTPS → Default Region: your Cloudflare address + /alexa → certificate: “My development endpoint is a sub-domain of a domain that has a wildcard certificate…” → Save.
  5. Copy the Skill ID (top of the Endpoint page, amzn1.ask.skill.…), paste it above, and Save here.
  6. Test tab → set “Skill testing is enabled in” to Development. Your Echo can now use it: “Alexa, open led wall”.
After adding or renaming favourites/scenes, paste the model again and Build so Alexa knows the names. If the invocation name is changed here, change it in the JSON too (or re-paste).
